# SEEKWAY Web 数据展示规范

本文件按 SEEKWAY V2.1.0 适配 DeliveryNote；来源与项目差异见 [README](../README.md#codex-规范接入)。

本文件是 `docs/web-ui-standard.md` 的专项扩展。任务涉及表格、列表、数据状态、数据格式、图标、图片或图表时必须读取。

## 1. 表格与列表

- 文本默认左对齐，数字和金额右对齐，状态可居中；同类列必须统一。
- 表头表达数据含义和单位，不把筛选条件、帮助说明全部塞入表头。
- 优先沿用当前页面已确认的表格密度；新表格无可复用模式时采用 `48px` 基准，高密度页面可使用 `40px`。表头高度保持一致，不因接入规范修改已有表格。
- 操作列放在末尾并保持稳定，常用操作直接展示，低频操作收纳到菜单。
- 排序、筛选和分页状态必须可见；返回列表时应尽量保留用户状态。
- 空数据必须区分“尚无数据”和“筛选无结果”，分别提供创建或清除筛选的下一步。
- 加载时使用骨架、局部加载或进度提示；局部刷新不得阻塞无关区域。
- 批量操作必须显示已选数量，并在执行前说明作用范围。
- 默认分页适用于可增长的数据集合；只有数据量已知且很小时才一次性展示全部数据。

## 2. 数据页面状态

每个数据页面至少包含：

1. 首次加载。
2. 正常数据。
3. 尚无数据。
4. 筛选无结果。
5. 请求失败并可重试。
6. 无权限。

## 3. 数据格式

- 日期默认使用 `YYYY-MM-DD`，日期时间使用 `YYYY-MM-DD HH:mm`；数据库和后台任务使用 UTC，Web 统一显示北京时间，跨时区歧义时标明时区。沿用现有日期格式化工具。
- 金额必须显示币种或货币符号，并按业务精度格式化；不得只显示无单位数字。
- 大数字使用千位分隔；百分比明确小数位规则；空值统一显示 `—`，不得混用空字符串、`null` 和 `N/A`。
- 枚举状态显示业务文案，不直接展示后端原始代码。

## 4. 图标、图片和可视化

- 新项目统一使用 `@ant-design/icons` 6；现有项目继续使用已确认的单一图标体系，不用 Emoji 代替业务图标。
- 默认使用线性图标：行内图标 `16px`、按钮图标 `18px`、区块图标 `20px`、空状态图标 `28–32px`；现有项目按其体系映射。
- 不得引入第二套图标库；缺少特殊业务图标时先复用项目资产，新增依赖须获得批准。
- 图标不能单独承担复杂含义；不熟悉的图标必须配文字或提示。
- 后台页面不使用无业务价值的装饰图、人物插画和大面积背景图。
- 图表必须有标题、单位、图例和数据来源；颜色之外还应使用标签、线型或形状区分类别。
- 关键数据不能只存在于图表中，应提供数值、摘要或可访问的替代信息。
